## 한 주제 진행 순서

1. 강의·자료를 읽고 목표와 예상 동작을 적습니다.
2. 먼저 직접 구현하고 실행합니다.
3. Codex에 코드 리뷰를 요청하고 문제 원인을 설명받습니다.
4. 직접 수정하거나 수정 범위를 지정해 반영합니다.
5. 필요한 경계 조건·실행 결과를 확인합니다. 성능 주장은 측정 조건과 함께 기록합니다.
6. 주제 폴더 README에 구현·실행법·검증 결과를 적고 STUDY_LOG를 갱신합니다.
7. Obsidian에 내 이해·면접 답변·미해결 질문을 정리하고 코드 위치를 연결합니다.
8. 변경 내용을 확인한 뒤 Git으로 커밋합니다. GitHub 업로드는 별도로 진행합니다.

- Obsidian: 개념, 내 말로 설명한 내용, 면접 답변, 헷갈리는 점, 관련 개념 링크, 복습.
