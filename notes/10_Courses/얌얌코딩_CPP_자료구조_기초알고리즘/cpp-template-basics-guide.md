# C++ 템플릿 기초

[학습 목차](00_수강목록.md) · [관련 실습](../../../01-yamyam-basic/AddNode_LinkedList.cpp) · [연결 리스트 구현](cpp-linked-list-implementation-guide.md)

## 핵심

템플릿은 타입만 다른 같은 알고리즘이나 자료구조를 하나의 정의로 작성하고, 사용한 타입에 맞는 코드를 컴파일 시점에 생성하는 기능입니다. `typename`과 `class`는 템플릿 타입 매개변수 자리에서 같은 뜻으로 사용할 수 있습니다.

```cpp
template <typename T>
T Add(T left, T right) {
    return left + right;
}
```

| 구분 | 쓰임 | 현재 실습 |
| --- | --- | --- |
| 함수 템플릿 | 타입이 다른 같은 연산 재사용 | `Add<T>` |
| 클래스 템플릿 | 타입과 무관한 자료구조 구현 | `Node<T>` |
| 명시적 특수화 | 특정 타입에만 다른 동작 제공 | `Add<int>` |

컴파일러는 실제로 사용된 타입을 바탕으로 템플릿을 구체화합니다. 타입 안전성과 재사용성이 장점이지만, 많은 타입·복잡한 헤더 템플릿은 빌드 시간과 생성 코드 크기를 늘릴 수 있습니다. 같은 코드가 단순히 `int`, `float`에서만 필요하다면 템플릿이 적합한지 먼저 판단합니다.

## 현재 실습 코드 상태

`AddNode_LinkedList.cpp`에는 `Add<T>`와 `int`용 명시적 특수화, `Node<T>` 초안이 있습니다. `Add<int>(3, 5)`는 특수화된 뺄셈 구현을 호출하므로 결과는 `-2`가 의도된 흐름입니다.

| 항목 | 상태 |
| --- | --- |
| `Add<T>` | `a + b`를 반환하는 함수 템플릿 작성 |
| `Add<int>` | 뺄셈을 반환하는 명시적 특수화 작성 |
| `Node<T>` | data와 next 멤버가 있는 클래스 템플릿 초안 |
| `main` | 같은 범위에 `ret`를 int와 float로 두 번 선언해 현재 빌드 전 단계 |
| 실행 결과 | 미기록 |

문서에서는 실습 코드를 수정하지 않았습니다. 한 범위에서는 변수 이름 하나를 한 번만 선언해야 하므로, 두 결과를 보관하려면 이름을 다르게 정하거나 별도 블록을 사용해야 합니다.
