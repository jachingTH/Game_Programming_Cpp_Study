## 궁금한 내용으로 찾기

- struct와 class의 차이, this 타입 → 클래스·구조체
- 초기화와 대입 차이, 소멸자 호출 → 생성자·소멸자
- v1 + v2의 의미와 구현 → 연산자 오버로딩
- 문자열 길이, 고정 버퍼, `+=` → MyString
- 조건 선택, 배열 비교, 2차원 인덱스 → 마스킹·인덱스
- 키를 인덱스로 쓰는 방식, 충돌, 단순 패턴 비교 → DAT·해시·패턴
- 널 종료 문자열, strcmp·strlen·복사 → cstring
- 격자 이웃, 이중 포인터, 2차원 패턴 → 방향·포인터·2D 패턴
- 3차원 인덱스와 삼중 반복 → 3차원 배열
- 종료 조건, 복귀, 경로 복구, 가지치기 → 재귀·백트래킹·가지치기
- 구조체 주소, ->, head와 next → 구조체 포인터·노드
- 동적 노드 추가, tail, 연결 리스트 순회 → AddNode·연결 리스트
- 타입 일반화, 함수·클래스 템플릿, 특수화 → 템플릿 기초
- 직접 만든 list, head·tail, 노드 연결과 소멸 → 연결 리스트 직접 구현
- new[], delete[], 문자열 이어 붙이기와 소유권 → MyString·동적 메모리
- 연결 리스트의 head·tail, prev·next, 자동·동적 저장 기간 → 연결 리스트 메모리 구조
- 클래스가 꼭 필요한지, 독립 함수와의 비교 → 멀티패러다임
