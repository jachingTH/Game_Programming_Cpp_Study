# 연산자 오버로딩과 Vector2

[학습 목차](00_수강목록.md) · [작성 중인 실습 코드](../../../01-yamyam-basic/01_Calculation_Overloading.cpp)

## 빠른 요약

연산자 오버로딩은 사용자 정의 타입에 연산자 표현을 제공하는 함수입니다. 좌표를 더할 때 x·y 계산을 반복하는 대신 `v1 + v2`로 의도를 나타낼 수 있습니다.

멤버 operator+가 선택되는 예제라면 `v1 + v2`는 `v1.operator+(v2)`로 이해할 수 있습니다. 비멤버 연산자 함수도 있으므로 모든 오버로딩이 멤버 호출인 것은 아닙니다. 우선순위나 피연산자 개수도 임의로 바꾸지 못합니다. [C++ 초안: 연산자 함수](https://eel.is/c++draft/over.oper)

## 노트와 실제 코드의 차이

| 항목 | Obsidian 설명 예제 | 현재 저장소 코드 |
| --- | --- | --- |
| 연산자 본문 | 좌표를 더하거나 빼서 결과 객체 반환 | operator+ 본문이 비어 있음 |
| 반환 타입 | Vector2 | void |
| 오른쪽 피연산자 | const Vector2& | Vector2 값 전달 |
| 호출 | 객체끼리 +, - 수행 | 좌표별 덧셈으로 ret를 직접 생성 |
| 실행 결과 | 예제 출력과 예상값 제시 | 이번 정리에서 실행하지 않음 |

따라서 현재 구현은 완료 상태가 아닙니다. 기존 학습 코드는 그대로 두고 차이를 기록합니다.

## 현재 코드에서 시작하기

`v1`은 (1,2), `v2`는 (3,4)이고 `ret(v1.x + v2.x, v1.y + v2.y)`로 결과를 만듭니다. 코드상 ret는 (4,6)으로 예상되지만 출력이나 검증 코드는 없습니다.

다음 구현 목표는 그 좌표 합산을 operator+ 안에서 표현하고 결과 Vector2를 반환하는 것입니다. 일반적인 덧셈 의미를 의도한다면 원본 두 객체는 그대로 두고 새 결과를 만듭니다.

## 문법을 읽는 방법

노트의 `Vector2 operator+(const Vector2& other) const`는 다음 의미입니다.

- 앞의 Vector2: 계산 결과를 값으로 반환.
- const Vector2&: 오른쪽 객체를 참조로 받아 이 경로로 수정하지 않음.
- 끝의 const: 왼쪽 객체의 일반 멤버를 이 함수를 통해 수정하지 않음.

작은 타입에서 참조가 항상 더 빠르다고 가정하지 않습니다. 여기서는 인터페이스의 의미를 먼저 이해합니다.

## 다음 검증 항목

- [ ] operator+에서 좌표 합을 반환하도록 직접 구현.
- [ ] v1 + v2가 (4,6)인지 확인.
- [ ] 연산 뒤 v1·v2가 바뀌지 않았는지 확인.
- [ ] 0과 음수 좌표 예제로 확인. int 범위를 넘는 합은 별도로 고려.

위 항목은 앞으로 할 일이며 완료한 테스트가 아닙니다.
