# 생성자·소멸자와 멤버 초기화

[학습 목차](00_수강목록.md) · [실습 코드](../../../01-yamyam-basic/00_Class_constructor_destructor.cpp)

## 빠른 요약

생성자는 객체를 사용할 수 있는 초기 상태로 만들고, 소멸자는 객체가 소유한 자원의 정리를 담당합니다. 정수 멤버를 0으로 바꾸는 것과 메모리를 해제하는 것은 다릅니다.

## 초기화와 대입의 차이

현재 코드의 `Test() : a(0), b(0) {}`는 본문 실행 전에 a와 b를 초기화합니다. 생성자 본문에서 `a = 0`을 쓰는 것은 대입입니다. 클래스 타입 멤버는 기본 생성 후 대입하는 대신 직접 초기화할 수 있습니다. const·참조 멤버도 초기화가 필요합니다.

멤버 초기화 순서는 이니셜라이저에 적은 순서가 아니라 클래스의 멤버 선언 순서를 따릅니다. “이니셜라이저가 항상 더 빠르다”는 식으로 성능을 단정하기보다 초기화 의미와 불필요한 작업을 구분합니다. [C++ 초안: 초기화](https://eel.is/c++draft/class.base.init)

## 현재 코드의 흐름

| 순서 | 코드 | 코드상 의미 |
| --- | --- | --- |
| 1 | Test t1; | 기본 생성자로 a=0, b=0 |
| 2 | t1.a=0; t1.b=0; | 이미 초기화된 멤버에 다시 대입 |
| 3 | Test t2(5, 10); | 인자에 맞는 생성자로 a=5, b=10 |
| 4 | main 종료 | 이 범위에서는 t2, t1 순서로 소멸 |

위 값과 순서는 코드를 읽고 정리한 예상이며, 이번 작업에서 실행·디버거로 관찰한 결과는 아닙니다.

## 소멸자와 자원 해제

현재 `~Test()`는 정수 멤버 a와 b에 0을 대입합니다. 이 클래스에는 직접 관리하는 동적 자원이 없으므로 이것이 메모리 해제에 필요한 처리는 아닙니다.

소멸자 호출과 저장 공간 반환은 구분합니다. 일반적인 자동 지역 객체는 범위를 벗어날 때 소멸하지만, 동적으로 만든 객체는 적절한 소유권 관리가 필요합니다. “모든 지역 변수는 반드시 스택에 있다”보다 저장 기간과 수명 규칙으로 이해합니다. [C++ 초안: 소멸자](https://eel.is/c++draft/class.dtor)

## 원문에서 보완한 점

- 모든 객체가 초기화되지 않는다고 일반화하지 않습니다. 타입과 초기화 방식에 따라 다르며, 초기화하지 않은 기본형 멤버를 읽지 않도록 합니다.
- 생성자 본문 대입과 멤버 직접 초기화를 구분했습니다.
- 소멸자가 정수를 0으로 만드는 것이 메모리 해제라는 오해를 구분했습니다.
