# 마스킹, 탐색 함수, 인덱스와 배열 비교

[학습 목차](00_수강목록.md) · [실습 코드](../../../01-yamyam-basic/02_Masking_Flag_Count_Index_ETC.cpp)

## 핵심

이 실습은 배열을 순회해 조건에 맞는 값을 고르고, 존재 여부를 함수로 분리하며, 기준 위치와 상대 위치를 계산하는 연습입니다. 코드의 `mask` 배열은 비트 연산이 아니라 각 원소가 0 또는 1인 선택 배열입니다.

## 현재 코드에서 읽을 수 있는 내용

| 주제 | 코드 | 의미 |
| --- | --- | --- |
| 선택 마스크 | `mask[i] == 1` | 선택된 위치의 `vect[i]`만 result와 출력에 반영 |
| 존재 검사 | `isExist` | 전역 배열에서 목표 값을 순차 탐색 |
| 결과 출력 | `printResult` | 탐색과 출력 책임을 분리 |
| 다중 탐색 | `finds`와 중첩 반복 | 여러 목표 값을 배열에서 각각 확인 |
| 배열 비교 | `isSame` | 같은 위치의 문자를 차례로 비교 |
| 기준·오프셋 | 주석의 `BaseIndex + OffsetIndex` | 큰 배열 안에서 지역 위치를 전역 위치로 바꾸는 모델 |

## 주의할 점

- `mask` 배열은 비트 배열 자체가 아닙니다. 비트 플래그를 다룰 때는 `&`, `|`, `^`, `<<` 같은 비트 연산의 규칙을 별도로 확인합니다.
- `size_t`는 요소 개수와 인덱스에 쓰기 위한 부호 없는 타입이지만 특정 기본 타입의 별칭이라고 고정하면 안 됩니다. 구현과 플랫폼에 따라 달라질 수 있습니다. [C++ 표준 초안: cstddef](https://eel.is/c++draft/cstddef.syn)
- 배열 이름은 많은 식에서 첫 원소 포인터로 변환됩니다. `arrA == arrB`는 내용이 아니라 주소를 비교합니다. 배열 내용 비교는 길이와 각 원소를 함께 비교해야 합니다.
- 문자 배열 비교는 널 문자를 만난 시점에도 비교를 끝낼 조건을 정해야 합니다. 현재 `isSame`은 최대 256칸을 비교하므로, 두 버퍼의 사용 범위와 널 종료를 전제로 합니다.

## 인덱스 모델

1차원 배열의 `arr[offset]`는 첫 원소를 기준으로 `offset`만큼 떨어진 위치를 가리킵니다. 2차원 데이터를 한 배열에 저장할 때는 예를 들어 `index = row * width + column`으로 지역 좌표를 오프셋으로 바꿀 수 있습니다. 여러 청크를 한 배열에 연속 저장하면 `finalIndex = chunkBase + localOffset`으로 접근합니다.

이 계산은 타일맵·청크·메시 버퍼처럼 연속 데이터에서 쓸 수 있습니다. 실제 그래픽 API의 인덱스·기준 정점 규칙은 API마다 다르므로 별도 문서로 확인합니다.
