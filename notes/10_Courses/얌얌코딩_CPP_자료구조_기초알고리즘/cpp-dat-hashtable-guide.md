# DAT, 해시 테이블, 패턴 탐색

[학습 목차](00_수강목록.md) · [실습 초안](../../../01-yamyam-basic/03_DAT.cpp)

## 핵심

Direct Address Table(DAT)은 키의 범위가 작고 미리 정해졌을 때, 키를 배열 인덱스로 바로 쓰는 방식입니다. 문자 빈도라면 `bucket[static_cast<unsigned char>(ch)]`처럼 출현 횟수를 기록할 수 있습니다.

| 구분 | DAT | 해시 테이블 |
| --- | --- | --- |
| 인덱스 | 키 자체 | 해시 함수가 계산한 버킷 번호 |
| 충돌 | 키를 직접 쓰므로 없음 | 서로 다른 키가 같은 버킷에 올 수 있음 |
| 공간 | 키 범위 K에 비례 | 버킷 수와 저장한 원소 수에 비례 |
| 조회 | 범위가 유효하면 O(1) | 평균 O(1), 충돌 처리와 부하율의 영향 있음 |

DAT는 해시 테이블과 같은 말이 아닙니다. DAT는 제한된 키 범위에 공간을 미리 쓰는 단순한 경우이고, 해시 테이블은 일반 키를 제한된 버킷 공간에 배치하면서 충돌을 처리합니다.

## 시간 복잡도

문자열 길이를 N, 문자 범위를 K라고 하면, 빈도 기록은 O(N), 버킷 전체 출력은 O(K)입니다. 계수 정렬은 값 범위가 K일 때 O(N + K)이며, K가 매우 크면 DAT의 공간 비용이 커집니다.

`03_DAT.cpp`에는 패턴 탐색, DAT, 해시 함수 초안이 함께 있습니다. 현재 문법이 완성되지 않아 빌드 가능한 상태가 아닙니다.

| 위치·항목 | 현재 상태 | 다음 확인 |
| --- | --- | --- |
| 패턴 탐색 반복 | `i < ;`가 비어 있어 컴파일 오류 | text 길이와 pattern 길이로 마지막 시작 위치를 계산 |

| `result` | 초기값 0이며 일치 시 갱신 흐름이 불완전 | 함수 반환값을 바로 사용해 계약 단순화 |
| `hashFunction` | `1 / 2`는 정수 나눗셈이라 0 | 버킷 수에 맞는 해시와 충돌 처리 방식을 정의 |

| 버킷 출력 | 안쪽 `i`가 바깥 i를 가림 | 버킷 인덱스와 반복 횟수 변수 분리 |

## 패턴 탐색

가장 단순한 방식은 text의 가능한 모든 시작 위치에서 pattern의 문자를 차례로 비교하는 것입니다. text 길이를 N, pattern 길이를 M이라고 하면 최악 시간은 O(NM)입니다. 길이 검사 없이 `text[start + offset]`에 접근하면 범위를 벗어날 수 있으므로, 시작 위치는 `start + M <= N`을 만족해야 합니다.
