# MyString과 동적 메모리

[학습 목차](00_수강목록.md) · [실습 코드](../../../01-yamyam-basic/MakingStringClass.cpp) · [고정 버퍼 MyString](cpp-string-class-guide.md) · [생성자·소멸자](cpp-constructor-destructor-guide.md)

## 핵심

직접 만든 문자열 클래스는 동적 문자 배열의 소유권을 통해 생성자, 소멸자, 재할당을 연습할 수 있습니다. C 스타일 문자열을 저장하려면 문자 수뿐 아니라 끝의 널 문자 `\0`를 위한 한 칸도 함께 할당해야 합니다.

```cpp
// 길이가 len인 문자열의 저장 공간
char* buffer = new char[len + 1];
// ... 문자 복사
buffer[len] = '\0';
delete[] buffer;
```

`std::string`은 가변 길이 문자열을 제공하는 표준 클래스입니다. 그 내부 저장 방식은 구현에 따라 다르므로, `char*`와 `new[]`를 직접 쓴다고 가정하지 않습니다. 학습용 `MyString`은 직접 소유권을 다루는 예제이고, 일반 코드에서는 `std::string`을 우선 사용합니다.

## += 와 재할당

고정 크기의 동적 배열은 뒤로 늘릴 수 없으므로, 이어 붙이기는 새 배열을 할당하고 기존·추가 문자열을 복사한 뒤 이전 배열을 `delete[]` 하는 순서로 처리합니다.

1. 기존 길이와 추가 길이를 계산한다.
2. 널 문자를 포함한 새 배열을 할당한다.
3. 기존 내용과 추가 내용을 순서대로 복사하고 끝에 `\0`를 둔다.
4. 이전 배열을 `delete[]` 하고 멤버 포인터·길이를 새 값으로 바꾼다.

반환형을 `MyString&`로 두고 `return *this;`를 하면 `a += "x"` 결과를 다시 참조할 수 있습니다. 현재 실습의 `operator+=`는 `void`이므로 이 동작은 아직 구현하지 않았습니다.

## 현재 실습 코드 상태

`MakingStringClass.cpp`는 `ya::string`, `std::string`, `std::vector` 사용 예제를 함께 둔 초안입니다.

| 항목 | 상태 |
| --- | --- |
| 인자 생성자 | `mStr - new char[len + 1]`로 작성되어 대입이 아니므로 현재 빌드 전 단계 |
| 기본 생성자 | `mStr`은 nullptr로 초기화하지만 `mLen`은 초기화하지 않음 |
| `operator+=` | 새 배열을 만들고 복사하려는 흐름은 있음. 이전 배열이 `new[]`로 할당됐다면 `delete[]`가 필요하지만 현재는 `delete` 사용 |
| 널 문자 | 추가 문자열 복사 반복이 끝의 널 문자까지 복사하도록 작성됨 |
| `erase()` | 문자만 0으로 바꾸며 길이와 소유권 상태는 갱신하지 않음 |
| `main` | `yaHello`를 같은 범위에서 두 번 선언해 현재 빌드 전 단계 |
| 실행 결과 | 미기록 |

문서에서는 실습 코드를 수정하지 않았습니다. 복사 생성·복사 대입을 따로 정의하지 않은 상태에서 동적 포인터를 가진 객체를 복사하면 얕은 복사와 이중 해제가 생길 수 있으므로, 이후에는 Rule of Three/Five 또는 `std::string` 기반 설계를 함께 확인해야 합니다.
