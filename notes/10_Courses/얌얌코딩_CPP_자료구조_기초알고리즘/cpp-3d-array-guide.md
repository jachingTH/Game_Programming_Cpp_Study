# 3차원 배열

[학습 목차](00_수강목록.md) · [관련 실습](../../../01-yamyam-basic/Recursive_function.cpp)

## 핵심

`int arr[depth][row][column]`은 2차원 배열들을 여러 개 가진 배열입니다. C++에서 마지막 인덱스가 가장 빠르게 변하므로 `arr[z][y][x]`를 순회할 때 일반적으로 z → y → x 순서의 중첩 반복이 자연스럽습니다.

| 인덱스 | 예시 의미 |
| --- | --- |
| z | 층·면·깊이 |
| y | 행 |
| x | 열 |

현재 실습은 `int arr[2][2][5]`에 삼중 반복으로 1을 채웁니다. 실행 결과는 아직 기록되지 않았습니다.

## 주의점

- 3차원 배열은 자동으로 게임 월드의 3차원 공간을 뜻하지 않습니다. 각 축에 어떤 의미를 부여할지 정해야 합니다.
- 차원이 늘어날수록 인덱스 순서가 헷갈리기 쉬우므로 상수 이름이나 작은 구조체를 사용해 의미를 드러냅니다.
- 고정 크기가 아니라 동적 크기·희소 데이터가 필요하면 1차원 평탄화나 다른 자료구조를 검토합니다.
