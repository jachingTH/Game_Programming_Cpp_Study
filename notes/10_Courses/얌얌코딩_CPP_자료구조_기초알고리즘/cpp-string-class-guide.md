# MyString으로 배우는 문자열 클래스

[학습 목차](00_수강목록.md) · [실습 코드](../../../01-yamyam-basic/01_Making_String_Class.cpp)

## 핵심

문자열을 내부 문자 배열과 길이로 묶어 보면 생성자, 캡슐화, `size()`, `operator+=`가 어떤 책임을 갖는지 배울 수 있습니다. 실제 프로그램에서는 직접 만든 고정 배열 문자열보다 `std::string`을 우선 사용합니다. `std::string`은 가변 길이 문자 시퀀스를 위한 표준 클래스입니다. [C++ 표준 초안: 문자열 클래스](https://eel.is/c++draft/string.classes)

## 현재 실습 코드의 구조

| 구성 | 의도 |
| --- | --- |
| `char str[256]` | 널 종료 C 문자열을 저장할 고정 버퍼 |
| `int len` | 문자열 길이를 저장하려는 멤버 |
| `MyString(const char*)` | 문자 배열을 내부 버퍼로 복사하려는 생성자 |
| `size()` | 저장된 길이를 반환하려는 함수 |
| `operator+=` | 문자열 뒤에 다른 문자열을 붙이려는 연산자 |

## 코드와 학습 노트의 차이

현재 소스는 실습 중인 상태입니다. 다음 항목은 완료한 기능이 아닙니다.

| 항목 | 현재 상태 | 이유 |
| --- | --- | --- |
| `len` 초기화 | 없음 | 생성자에서 값을 넣지 않아 `size()` 결과를 신뢰할 수 없음 |
| `size()` | `len + 1` 반환 | 일반적으로 길이는 널 문자를 제외한 문자 수를 뜻함 |
| `operator+=` | 반환형은 `int`, 반환문 없음 | 함수 계약과 구현을 정해야 함 |
| `operator+=` 복사 | `str[i]`를 읽음 | 매개변수와 멤버 이름이 같아 의도한 입력 문자열을 읽지 못함 |
| 버퍼 경계 | 보장 없음 | 추가 문자열이 255자를 넘지 않도록 검사해야 함 |
| `str2 = "EFGH"` | 대입 연산자 미작성 | 암묵 변환과 컴파일러 생성 대입에 의존하게 되므로 학습 목적에 맞게 분리해 확인할 필요가 있음 |

코드를 이번 정리에서 수정하거나 실행하지 않았습니다.

## 구현할 때 지킬 규칙

1. 생성자에서 `len = 0`으로 시작하고, 복사 뒤 실제 문자 수를 저장합니다.
2. 버퍼는 널 문자 자리를 남겨 최대 255자까지만 저장합니다.
3. `operator+=`는 보통 객체 자신을 반환하는 `MyString&` 형태로 설계합니다. 이 문서에서는 구현 전이므로 확정하지 않았습니다.
4. 덧붙이기 전 남은 공간을 계산하고, 긴 입력을 어떻게 처리할지 정합니다.
5. `size()`는 일반적으로 널 문자를 제외한 길이를 반환합니다. 표준 문자열도 `data() + size()` 위치에 널 문자를 제공하지만 그 종결 문자는 size에 포함되지 않습니다. [C++ 표준 초안: basic_string](https://eel.is/c++draft/string.classes)
