## 방향 배열

상·하·좌·우 같은 인접 칸을 찾을 때 `(dy, dx)` 오프셋 배열을 반복하면 같은 코드를 네 번 쓰지 않아도 됩니다. 새 좌표를 계산한 뒤에는 항상 배열 경계를 검사합니다.

```cpp
const int dy[4] = {-1, 1, 0, 0};
const int dx[4] = {0, 0, -1, 1};
```

현재 실습에서는 중앙 `(1, 1)`의 네 이웃 값을 더하려고 하며, 범위 검사 뒤 `arr1[newY][newX]`를 사용합니다.

## 이중 포인터

`int** pp`는 `int*`를 가리키는 포인터입니다. 코드의 `*(*pp) = 200`은 `pp → p → a` 경로를 따라 a 값을 바꾸려는 예제입니다. 이중 포인터는 포인터 자체를 바꿔야 하는 함수 호출이나 포인터 배열에서 사용하지만, 단순 값 변경에는 필요하지 않습니다.

## 2차원 패턴 탐색

큰 배열의 가능한 시작 좌표마다 작은 패턴을 비교합니다. map의 크기를 H×W, pattern의 크기를 PH×PW라면 시작 좌표는 `startY + PH <= H`와 `startX + PW <= W`를 만족해야 합니다. 단순 비교의 최악 시간은 시작 위치 수와 패턴 크기의 곱에 비례합니다.

## 현재 실습 코드 상태

| 항목 | 상태 |
| --- | --- |
| 방향 배열과 경계 검사 | 코드에 작성됨, 실행 결과 미기록 |
| 이중 포인터 | `a → p → pp` 예제 작성됨 |
| 패턴 비교 함수 | 전역 map과 pattern을 기준으로 작성됨 |
| 빌드 | 같은 `main` 범위에서 `int a`를 두 번 선언해 현재 컴파일 오류 |
| 패턴 대상 map | main의 지역 map은 전역 map을 가려도 `isPattern`은 전역 map을 사용 |

학습 코드는 수정하지 않았습니다. 중복 선언을 해소하고, 찾은 시작 좌표를 출력한 뒤에 결과를 기록합니다.
