# C 스타일 문자열과 cstring

[학습 목차](00_수강목록.md) · [관련 코드 파일](../../../01-yamyam-basic/Cpp_cstring_Library.cpp)

## 핵심

C 스타일 문자열은 마지막에 널 문자 `\0`을 둔 char 배열입니다. 문자열 함수는 널 문자를 찾을 수 있다고 가정하므로, 널 종료가 보장되지 않은 버퍼에 `strlen`, `strcmp`, `strcpy`를 사용하면 안전하지 않습니다.

| 함수 | 역할 | 반환·주의점 |
| --- | --- | --- |
| `strlen` | 널 문자 전까지 길이 계산 | 널 문자는 길이에 포함하지 않음 |
| `strcmp` | 두 문자열의 사전식 비교 | 같으면 0, 부호만 비교에 사용 |
| `strcpy` | src를 dest로 복사 | dest 크기가 충분해야 함 |

배열 이름을 `==`로 비교하면 보통 배열의 첫 원소 주소를 비교하게 됩니다. 내용 비교에는 `strcmp`나 길이·원소 비교가 필요합니다.
