# 게임 프로그래밍 학습 홈

목표: C++와 게임 개발 원리를 직접 구현하고, 이해한 내용을 면접에서 내 말로 설명하기.

## 시작 방법

1. 이 폴더 `D:\Obsidian\Obsidian Vault\Learning_Programming`을 Obsidian Vault로 엽니다.
2. 설정 → 코어 플러그인 → Templates(템플릿)를 활성화합니다.
3. Templates 설정에서 템플릿 폴더를 `Templates`로 지정합니다.
4. 해당 분야 폴더에 새 노트를 만들고 명령 팔레트의 템플릿 삽입을 실행합니다.
5. 개념은 Concept, 구현 분석은 Implementation, 프로젝트는 Project, 일일 복습은 Daily를 사용합니다.

`{{title}}`, `{{date:YYYY-MM-DD}}`는 코어 Templates 플러그인으로 삽입할 때 치환됩니다. 대괄호로 표시된 작성 안내는 직접 바꿉니다. 추가 플러그인은 필요하지 않습니다.

## 학습 순서

Yamyam Basic → Yamyam Advanced → Modern C++ → 공간 알고리즘 → 성능 → OS·동시성 → 설계 패턴 → Unreal C++. 작은 통합 프로젝트는 배운 범위에서 병행합니다.

진도 체크의 기준 파일은 저장소 `ROADMAP.md`입니다. 이곳에서는 개념 연결·내 설명·면접 답변·복습을 관리합니다.
